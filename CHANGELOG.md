# Changelog

Todos los cambios notables en este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-13

### Added
- Integración de lienzo interactivo Tldraw sin SSR.
- Editor y vista previa dividida para documentación Markdown.
- Plantilla para inserción rápida de ADRs.
- Store global en Zustand para gestión de diagramas y autoguardado.
- Barra lateral para catálogo, búsqueda y filtrado por etiquetas.
- Modal para exportar referencias en Markdown y respaldo JSON del canvas.
- Configuración de tokens semánticos en Tailwind CSS.
